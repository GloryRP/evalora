  2. InvigilatorAssignments.jsx → 6 issues fixed

================================================================================
ROOT CAUSE
================================================================================

When Mongoose populates a reference (e.g., populate('examId')), if the 
referenced document doesn't exist or the reference is broken, the field 
becomes null instead of an object.

OLD CODE (vulnerable):
  const examId = allocation.examId._id  // ← CRASH if examId is null

NEW CODE (safe):
  if (!allocation.examId) return;       // Skip early
  const examId = allocation.examId._id?.toString() || allocation.examId?.toString();
